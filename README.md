## 🖥️ نصب روی سرور پولی (VPS)

این روش برای هر سرور لینوکس (Ubuntu/Debian) کار می‌کند.

### پیش‌نیازها

- یک سرور مجازی (VPS) با Ubuntu 20.04+ یا Debian 11+
- دسترسی root (sudo)
- پورت‌های باز: 443 (تلگرام) و یک پورت برای Adminer (پیش‌فرض 8080)

> 💡 سرورهای پیشنهادی: Hetzner (ارزان‌ترین)، Contabo، DigitalOcean، Vultr

### مراحل نصب

#### ۱. اتصال به سرور

```bash
ssh root@آی‌پی_سرور
```

#### ۲. دانلود فایل‌های ربات

```bash
# نصب git
apt update && apt install -y git

# کلون کردن پروژه
git clone https://github.com/omid-najafi/zar-bot.git
cd zar-bot
```

> اگر فایل‌ها را به‌صورت دستی آپلود کرده‌اید، به پوشه ربات بروید: `cd /path/to/zar-bot`

#### ۳. اجرای اسکریپت نصب

```bash
sudo bash install.sh
```

اسکریپت از شما می‌پرسد:

| سوال | توضیح |
|------|--------|
| **توکن ربات** | از [@BotFather](https://t.me/BotFather) بگیرید |
| **آیدی عددی ادمین** | از [@userinfobot](https://t.me/userinfobot) بگیرید |
| **موجودی شروع** | مبلغ هدیه اولیه کاربران (اختیاری، پیش‌فرض ۰) |
| **نوع دیتابیس** | ۱ = نصب MySQL روی سرور (پیشنهادی) / ۲ = دیتابیس خارجی |
| **پورت Adminer** | پورت وب مدیریت دیتابیس (پیش‌فرض ۸۰۸۰) |

#### ۴. اسکریپت به‌صورت خودکار:

- ✅ پکیج‌های سیستمی (Python, MySQL, PHP) را نصب می‌کند
- ✅ دیتابیس MySQL و کاربر را می‌سازد (با رمز تصادفی قوی)
- ✅ Adminer (مدیریت دیتابیس تحت وب) را نصب می‌کند
- ✅ فایل `.env` را با تنظیمات شما می‌سازد
- ✅ وابستگی‌های Python را نصب می‌کند
- ✅ سرویس خودکار systemd می‌سازد (ربات همیشه روشن می‌ماند)
- ✅ فایروال را تنظیم می‌کند
- ✅ ربات را شروع می‌کند

#### ۵. در پایان، لینک مدیریت دیتابیس نمایش داده می‌شود:

```
🔗 لینک: http://آی‌پی_سرور:8080

اطلاعات ورود به Adminer:
  سیستم:     MySQL
  سرور:      localhost
  کاربر:     zarbot
  رمز:       (رمز تصادفی تولید شده)
  دیتابیس:   zarbot
```

از این لینک می‌توانید به دیتابیس دسترسی داشته باشید و تغییرات ایجاد کنید (تغییر موجودی کاربران، حذف کاربر، و غیره).

### نصب سریع در یک خط

اگر فایل‌ها را已经有 دارید:

```bash
cd zar-bot && sudo bash install.sh
```

## ☁️ نصب روی Railway

این روش برای استقرار رایگان ابری است.

### ۱. ساخت ربات

- به [@BotFather](https://t.me/BotFather) برو و با `/newbot` ربات بساز.
- توکن رو کپی کن.

### ۲. گرفتن آیدی عددی مالک

- به [@userinfobot](https://t.me/userinfobot) پیام بده و `id` خودت رو بردار.

### ۳. پروژه رو فورک کن

### ۴. دیپلوی روی Railway

- وارد [railway.app](https://railway.app) شو.
- `New Project` → `Deploy from GitHub repo` → ریپازیتوری رو انتخاب کن.
- در تب `Variables` این متغیرها رو اضافه کن:

| Variable | Value |
|---|---|
| `BOT_TOKEN` | توکن ربات |
| `OWNER_ID` | آیدی عددی مالک |
| `START_BALANCE` | (اختیاری) موجودی هدیه شروع |

### ۵. افزودن دیتابیس MySQL

- در Railway: `New` → `Database` → `Add MySQL`
- متغیرهای دیتابیس به‌صورت خودکار تنظیم می‌شوند (`MYSQLHOST`, `MYSQLPORT`, `MYSQLUSER`, `MYSQLPASSWORD`, `MYSQLDATABASE`)

### ۶. شروع بازی

- ربات رو به گروه اضافه کن (ترجیحاً ادمین).
- در گروه بنویس: `زربات`
- یا برای منوی بازی‌ها بنویس: `زر بازی`

## 🗄️ مدیریت دیتابیس

### از طریق Adminer (وب)

پس از نصب روی VPS، یک پنل وب برای مدیریت دیتابیس در دسترس است:

```
🔗 http://آی‌پی_سرور:8080
```

**اطلاعات ورود** (از `manage.sh` → گزینه ۶ قابل مشاهده):

| فیلد | مقدار |
|------|-------|
| سیستم | MySQL |
| سرور | localhost |
| کاربر | zarbot |
| رمز | (رمز تولید شده در نصب) |
| دیتابیس | zarbot |

با Adminer می‌توانید:
- ✅ مشاهده و ویرایش جداول
- ✅ اجرای کوئری SQL
- ✅ خروجی گرفتن (Export) از دیتابیس
- ✅ وارد کردن (Import) داده
- ✅ تغییر موجودی کاربران، حذف کاربر، و غیره

### جداول دیتابیس

| جدول | توضیح |
|------|-------|
| `users` | کاربران — موجودی (`balance`)، بانک (`bank_balance`)، XP (`total_xp`)، لول (`level`)، کارت (`card_number`) |
| `assets` | ملک‌ها و کارگرهای خریداری‌شده — نوع (`asset_type`), کلید (`asset_key`), درآمد روزانه (`daily_income`) |
| `user_missions` | ماموریت‌های روزانه کاربران |

### دستورات مفید MySQL

ورود به MySQL از خط فرمان:

```bash
mysql -u zarbot -p zarbot
```

کوئری‌های مفید:

```sql
-- مشاهده تمام کاربران
SELECT user_id, first_name, balance, bank_balance FROM users;

-- تغییر موجودی یک کاربر
UPDATE users SET balance = 1000000 WHERE user_id = 123456789;

-- بن کردن کاربر (حذف)
DELETE FROM users WHERE user_id = 123456789;

-- مشاهده دارایی‌های یک کاربر
SELECT * FROM assets WHERE user_id = 123456789;

-- آمار کلی
SELECT COUNT(*) as total_users, SUM(balance) as total_balance FROM users;
```

## 🛠️ مدیریت ربات پس از نصب

### اسکریپت مدیریت تعاملی

```bash
bash manage.sh
```

این اسکریپت یک منو با گزینه‌های زیر نمایش می‌دهد:

| گزینه | عملکرد |
|-------|--------|
| ۱ | 📊 وضعیت ربات |
| ۲ | 🔄 ری‌استارت ربات |
| ۳ | ▶️ شروع ربات |
| ۴ | ⏹️ توقف ربات |
| ۵ | 📋 لاگ زنده |
| ۶ | 🗄️ اطلاعات دیتابیس + لینک Adminer |
| ۷ | 📝 ویرایش فایل تنظیمات (.env) |
| ۸ | 📦 آپدیت ربات |
| ۹ | 🧹 پاک‌سازی لاگ‌ها |
| ۱۰ | 📊 اطلاعات سیستم |

### دستورات مستقیم systemd

```bash
# وضعیت
systemctl status zarbot

# ری‌استارت
systemctl restart zarbot

# توقف
systemctl stop zarbot

# شروع
systemctl start zarbot

# لاگ زنده
journalctl -u zarbot -f

# ۵۰ خط آخر لاگ
journalctl -u zarbot -n 50
```

### آپدیت ربات

```bash
cd zar-bot
git pull
bash manage.sh  # → گزینه ۸ (آپدیت)
```

یا دستی:

```bash
cd zar-bot
git pull
venv/bin/pip install -r requirements.txt
systemctl restart zarbot
```

### تغییر تنظیمات

```bash
nano /opt/zar-bot/.env
systemctl restart zarbot
```

## 🎮 امکانات ربات

### 💰 اقتصادی
- 🏦 **بانک** با سود ۲٪ روزانه (هر ساعت واریز خودکار)
- 🏠 **۱۴ نوع ملک** (سوپرمارکت تا مجتمع تجاری)
- 👷 **۱۲ نوع کارگر** (معلم تا فضانورد)
- 💸 **برداشت دستی درآمد** انباشته‌شده
- 🎭 **کاباره زر** با ۵ شخصیت
- 💸 **انتقال زرکوین** بین کاربران

### 🎮 بازی‌ها
- ✊ سنگ کاغذ قیچی (دونفره)
- ❌ دوز (دونفره)
- 🧠 کوییز (دونفره، ۱۹۰+ سوال)
- ⚽ پنالتی (تک‌نفره)

### 🎰 کازینو (۷ بازی)
- 🎰 اسلات
- 🎲 تاس
- 🪙 شیر یا خط
- 🃏 کارت شانس
- 🎡 رولت (قرمز/مشکی/صفر)
- 💣 مین‌یاب (۵ در، ۳ جواهر)
- 🎯 چرخ شانس (۶ قسمت)

### 🎯 ماموریت‌ها
- هر روز ۶ ماموریت تصادفی
- ۴۵ قالب ماموریت با ۱۹ نوع مختلف
- فیلتر هوشمند (کسی که تمام ملک‌ها را خریده، ماموریت خرید نمی‌گیرد)

### 🔒 امنیت
- هر کاربر فقط از منوی خودش استفاده می‌کند
- جوین اجباری کانال/گروه
- کارمزد ۱۰٪ روی بازی‌ها

### ⭐ سیستم لول
- XP از ماموریت‌ها و بازی‌ها
- لول = 2^level × 1000 XP نیاز
- هر لول پاداش «زر» بیشتری می‌دهد

## ❓ سوالات متداول

### ربات روشن نمی‌شود

```bash
journalctl -u zarbot -n 30
```

خطا را بررسی کنید. معمولاً مشکل از:
- توکن اشتباه → `.env` را ویرایش کنید
- دیتابیس در دسترس نیست → `systemctl status mysql`

### چطور موجودی یک کاربر را تغییر دهم؟

۱. به Adminer بروید: `http://آی‌پی_سرور:8080`
۲. با اطلاعات دیتابیس وارد شوید
۳. جدول `users` را باز کنید
۴. فیلد `balance` را ویرایش کنید

یا از خط فرمان:
```bash
mysql -u zarbot -p zarbot -e "UPDATE users SET balance=1000000 WHERE user_id=123456789;"
```

### چطور کانال‌های جوین اجباری را تغییر دهم؟

فایل `config.py` را ویرایش کنید:
```python
REQUIRED_CHANNELS = [
    {"name": "کانال شما", "id": "@your_channel", "url": "https://t.me/your_channel"},
]
REQUIRED_GROUP = {
    "name": "گروه شما",
    "id": -1001234567890,  # آیدی عددی گروه
    "url": "https://t.me/your_group",
}
```

سپس ری‌استارت: `systemctl restart zarbot`

### چطور بک‌آپ بگیرم؟

```bash
mysqldump -u zarbot -p zarbot > backup_$(date +%Y%m%d).sql
```

بازیابی:
```bash
mysql -u zarbot -p zarbot < backup_20240101.sql
```

### پورت Adminer را چطور عوض کنم؟

```bash
# ویرایش سرویس
nano /etc/systemd/system/zarbot-adminer.service
# پورت 8080 را به پورت دلخواه تغییر دهید

# اعمال تغییرات
systemctl daemon-reload
systemctl restart zarbot-adminer

# باز کردن پورت جدید در فایروال
ufw allow پورت_جدید/tcp
```

### ربات روی Railway هست، چطور دیتابیس را مدیریت کنم؟

در Railway:
۱. روی سرویس MySQL کلیک کنید
۲. تب `Data` را باز کنید
۳. جداول را مشاهده و ویرایش کنید

یا از یک کلاینت MySQL (مثل DBeaver یا MySQL Workbench) با اطلاعات Railway متصل شوید.
