# 🤖 ربات زرکوین (بات زر)

ربات بازی فان تلگرامی با کوین «زرکوین»، بانک با سود ۲٪ روزانه، ملک، کارگر، بازی‌های دونفره و تک‌نفره، انتقال زرکوین و پنل ادمین.

## 🚀 دیپلوی روی Railway

### 1. ساخت ربات
- به [@BotFather](https://t.me/BotFather) برو و با `/newbot` ربات بساز.
- توکن رو کپی کن.

### 2. گرفتن آیدی عددی مالک
- به [@userinfobot](https://t.me/userinfobot) پیام بده و `id` خودت رو بردار.

### 3. آپلود روی GitHub
- یک ریپازیتوری جدید بساز.
- فایل‌های پروژه رو push کن.

### 4. دیپلوی روی Railway
- وارد [railway.app](https://railway.app) شو.
- `New Project` → `Deploy from GitHub repo` → ریپازیتوری رو انتخاب کن.
- در تب `Variables` این متغیرها رو اضافه کن:

| Variable | Value |
|---|---|
| `BOT_TOKEN` | توکن ربات |
| `OWNER_ID` | آیدی عددی مالک |
| `START_BALANCE` | (اختیاری) موجودی هدیه شروع، پیش‌فرض `0` |

### 5. 🔴 افزودن Volume (بسیار مهم)
دیتابیس SQLite روی فایل‌سیستم Railway **موقتی** هست و با هر دیپلوی پاک میشه. برای حفظ اطلاعات:
- روی سرویس ربات کلیک کن.
- تب `Volumes` → `Add Volume`.
- **Mount Path** رو دقیقاً `/data` بذار.
- کد به‌صورت خودکار از `RAILWAY_VOLUME_MOUNT_PATH` استفاده می‌کنه.

### 6. شروع بازی
- ربات رو به گروه اضافه کن (ترجیحاً ادمین).
- در گروه بنویس: `زربات`
- یا برای منوی بازی‌ها بنویس: `زر بازی`

## 🎮 امکانات
- 🏦 بانک با سود ۲٪ روزانه ساعت ۰۰:۰۰ به وقت تهران
- 🏠 خرید ملک (حداکثر ۵ ملک)
- 👷 استخدام کارگر (حداکثر ۵ کارگر)
- 🎮 سنگ کاغذ قیچی، دوزه، کوییز، پنالتی، شانسی
- 💸 انتقال زرکوین با کارمزد ۱٪ بالای ۱٬۰۰۰٬۰۰۰
- 👑 پنل ادمین با ریپلای «انتقال زرکوین ...»
